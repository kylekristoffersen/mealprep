Meal Prep Planner: self-hosted replacement for the Claude artifact + Google Sheet.
Run locally: pip install -r requirements.txt && python app.py   (data in ./_data, http://localhost:5020)
Tests: with the app running on a fresh data folder, import tests/sample-data.json (Settings > Bring in your data) then: python tests/browser_test.py
Hosting notes: deploy/README.md
